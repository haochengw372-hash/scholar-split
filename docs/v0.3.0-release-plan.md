# v0.3.0 发布整理范围

1. 保留 Chrome、工作台和已有翻译接口行为，补齐可构建 Zotero 源码与完整 AGPL 本地翻译主机。
2. 先用测试锁定附件来源关联，再修复重命名导致的原文识别；不凭标题任意挑选多篇原文。
3. 删除发布对私人安装路径和上游自动覆盖更新的依赖。安装保留配置、数据库、论文和既有服务。
4. PDF2zh 与 PDF2zh-next 使用独立环境，不添加向量库、不打包 API Key 或个人论文。
5. 新鲜构建 XPI、安装与回归验证后，按白名单生成完整包、校验和及中文说明，上传 GitHub。

验证：插件单元测试和类型构建；服务测试；含空格的新安装路径与幂等安装；独立端口启动/停止与工作台接口；实际 PDF2zh-next 翻译；包内容及密钥检查；远程提交与 Release 资产。
