# ScholarSplit v0.3.4：修复语言资源破坏面板结构的回归

guide.16 注入窗口语言资源后，带正文值的 Fluent 消息替换了自定义控件的子节点，导致导读/问答栏只剩文字、右侧图标栏出现拥挤文字；这是上一版引入的回归。

- 面板标题只翻译 `.label`，侧栏及按钮只翻译 `.tooltiptext`，不再向控件主体写入文字或删除原有结构。
- 分离“重新生成”和“写作检查”的 DOM 提示消息与程序取值消息，保留现有操作文字及图标。
- 两种语言的全部 6 个原生 DOM 绑定均有属性专用检查，防止此问题再次出现。

请安装 `ScholarSplit-Zotero-4.1.8-guide.17.xpi`，随后完全退出 Zotero 再重新打开，清除旧语言资源和已被替换的控件实例；不需要修改服务配置、论文或文献库。
本版保留问答同步显示、当前 PDF 读取和 base64 修复；测试及构建通过不代替安装后的原生窗口确认。

原理参见 Mozilla 的 [DOM 本地化说明](https://firefox-source-docs.mozilla.org/l10n/fluent/tutorial.html#markup-localization)。
