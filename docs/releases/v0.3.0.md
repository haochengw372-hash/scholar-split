# ScholarSplit v0.3.0：完整翻译安装包与稳定原文关联

这版适用于想同时在 Zotero 和 Chrome 中翻译、导读和提问论文的研究者。
不再只有 Chrome 扩展和嵌入式模块：发行包提供完整本地翻译主机、可构建 Zotero 源码与 XPI。

## 新增与修复

- 默认集成 PDF2zh-next 2.9.0 + BabelDOC 0.6.2；可用 `--legacy` 独立安装 PDF2zh 1.9.11。
- Zotero 新译文保存稳定原文附件关联；改文件名和标题后，导读、翻译、问答与写作检查仍共用正确来源。旧译文只有同父条目唯一原文时才自动关联，多个候选不再猜最早附件。
- 论文问答按 PDF 内容哈希保存对话，附核验过的摘录与 PDF 页码。
- 导读 JSON 错误有一次重试；DeepSeek 写作检查保留红色定位批注。
- 安装器保留配置和数据，管理自己的服务进程；不终止占用 8890 的其他服务。
- 本机配对支持标准安装位置及自定义令牌文件路径，不再绑定开发者私人路径。
- 发布 ZIP 用 Git 文件白名单生成，附 XPI 与 SHA256SUMS；不带模型密钥、论文、数据库或模型缓存。

## 安装与更新

1. 下载 `scholar-split-v0.3.0.zip` 与 `SHA256SUMS`，校验后解压；需要 uv 和 Python 3.12。
2. 新安装运行 `./scripts/install.sh`。更新本安装器管理的服务先运行安装目录 `scripts/stop.sh`，再安装新包。旧 LaunchAgent 服务需另行迁移，安装器不会替换它。
3. Chrome 加载安装目录 `extension`；Zotero 从文件安装 `ScholarSplit-Zotero-4.1.8-guide.13.xpi`。
4. 在本机用 `server/.venv/bin/python server/configure.py` 无回显配置模型密钥。

Zotero XPI 沿用旧 PDF2zh 插件 ID，安装会替换旧导读版，但不移动文献或修改 PDF 原文。
首篇翻译需要获取官方字体及版面模型。安装指南和复制给 Agent 的一行指令见中文 README。

## 验证与边界

通过服务/索引/安装打包测试、Chrome 静态与单元测试、24 项 Zotero 测试及完整 TypeScript/XPI 构建。
全新含空格安装目录可启动工作台；现有服务与新安装的引擎均完成了 DeepSeek 驱动的合成 PDF 中文翻译。
用户真实 Zotero 文献中的点击流程仍需安装新版后确认；未宣称所有历史无关联附件都能自动判定。
