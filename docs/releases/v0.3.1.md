# ScholarSplit v0.3.1：直接问当前 PDF，新增引用信息

## Fixed

- Zotero 问答直接读取当前阅读器打开的 PDF，包括双语件和译文，不再强制寻找独立原文；页码引用和跳转绑定实际读取的附件。
- 阅读器提供父条目时，通过该阅读器 section 的 tabID 定位当前附件，不读取其他标签页的论文。

## Changed

- 独立 Chrome、工作台与项目工具从本版起采用 Apache-2.0；PDF2zh 衍生主机和 Zotero 集成继续遵循 AGPL，保留全部上游声明。
- README 首行请求研究使用者引用 Haocheng Wang；新增 CITATION.cff 和 NOTICE，发行包及安装目录均保留引用信息。
- 引用请求不构成额外许可证条件，此前 MIT 发行版本不被追溯改写。

## Upgrade

安装 `ScholarSplit-Zotero-4.1.8-guide.14.xpi` 后重新打开问答面板；无需重新翻译文章。
完整 ZIP 和 SHA256SUMS 随 Release 提供；本地服务、论文与对话数据库不被此次插件安装移动或删除。

30 项 Zotero 插件测试及 TypeScript 构建验证覆盖当前 PDF 读取、独立译文、父条目歧义、错误标签页、迟到请求及引用附件绑定。
