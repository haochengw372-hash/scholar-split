# ScholarSplit v0.3.3：修复展开后空白的问答栏

- 修复同一 PDF 元数据刷新触发 `onItemChange` 后清空界面、而 Zotero 渲染缓存不再调用异步绘制的问题。
- 同步 `onRender` 创建输入框，读取中或失败时也保留输入框；未读取完成时禁止发送，错误和重试提示保持可见。
- 同一 PDF 保留已加载会话和草稿，切换文章或同父条目下不同阅读器附件仍会使旧请求和引用失效。
- 向面板所属窗口注入 Fluent 语言资源，让标题显示“论文问答”，而不是只显示文件名。

对照本机 Zotero 的 `ItemPaneSectionElementBase` 和 `ItemPaneCustomSection` 生命周期实现新增回归测试，旧版在空白场景下失败，修复后通过；原生用户窗口点击流程尚需安装后确认。

请安装 `ScholarSplit-Zotero-4.1.8-guide.16.xpi` 后完全退出并重新打开 Zotero，本修复不要求更换服务或重新翻译论文。
