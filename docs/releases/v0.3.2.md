# ScholarSplit v0.3.2：修复 PDF 上传，导读读取当前附件

- 修复 Zotero 共用文件读取函数把完整 Data URL 当作 base64 上传的问题；问答和写作接口收到纯 base64，翻译与导读协议仍兼容。
- 导读读取当前打开/选中的原文、译文或双语 PDF，不再要求另有配对原文和翻译件。
- 导读按实际输入附件保存，保留其他附件的导读；独立 PDF 在附件笔记中保存并保留已有用户笔记。
- 导读引用跳转实际输入 PDF，同键导读不写入“译文来源”关系，不影响翻译或写作批注的原文定位。

验证包括实际文件 helper 的 Blob/FileReader → JSON 序列化、二进制字节往返，以及真实 Flask 问答注册和导读接口接受同一份合成双语 PDF；这些接口测试不调用模型。
模型生成效果与用户原生 Zotero 点击流程需要安装后确认，不把模拟环境测试说成已在用户文献上验证。

请从文件安装 `ScholarSplit-Zotero-4.1.8-guide.15.xpi`；这是插件侧修复，兼容现有服务，不需要重新翻译论文或改服务配置。
